What is X-Board

X-Board is an immutable programmable billboard. Connect a Stacks wallet, design a square, and let the page package the correct Clarity contract call. Each valid B1 programme updates one square.

Click any square. Choose text, an Xtrata inscription, or clear. The page generates a programme containing that square's stable wire code and the same style fields enforced by the Clarity contract.

The page is the compiler. The contract call carries the programme. Each square is an independent public state.
