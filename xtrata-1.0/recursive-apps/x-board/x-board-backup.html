What is X-Board

X-Board is an immutable programmable billboard. The code is fixed, but it reads public Stacks transfers sent to its address. Each valid B1 memo updates one square.

Click any square. Choose text, an Xtrata inscription, or clear. The page generates a memo containing that square's stable wire code.

The page is the compiler. The memo is the program. Each square is an independent public state.
