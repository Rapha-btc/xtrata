# Launch Campaign

This folder contains the launch campaign playbook, copy, assets checklist, and
tracking templates for promoting Xtrata across multiple platforms.

## Files
- `00-campaign-plan.md` - Overall strategy, audiences, phases, and tactics.
- `01-platform-playbooks.md` - Per-platform guidance and formats.
- `02-content-calendar-template.md` - A structured 6-week calendar template.
- `03-creative-asset-checklist.md` - Required graphics, demos, and visual specs.
- `04-copy-bank.md` - Reusable copy blocks, hooks, CTAs, and tags.
- `05-metrics-kpis.md` - KPI targets and tracking approach.
- `06-partnerships-outreach.md` - Partner outreach plan and templates.

## How to use
1) Start with `00-campaign-plan.md`.
2) Customize the platform playbooks to match current channels.
3) Fill out the calendar with real dates and owners.
4) Produce assets using the checklist.
5) Track results weekly with the KPI sheet.
