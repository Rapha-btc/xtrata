Why this homepage structure works

The protocol is broad, but the entry point should be narrow. This layout turns Xtrata into a choice-driven experience instead of an everything-at-once explanation.

Reduces confusion for new visitors
Makes each builder track legible
Creates clear pages LAB builders can own

How the payment layer fits

Xtrata can anchor the permanent data layer while STX, USDCx, and sBTC support value flow. That means builders can think in terms of storage + access + monetisation from day one.

STX: native ecosystem payments and contracts
USDCx: stable pricing and settlement
sBTC: Bitcoin-native value routes
