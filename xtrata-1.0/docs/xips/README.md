# Xtrata Improvement Proposals (XIPs)

XIPs define standards, formats, conventions and interoperability rules for the Xtrata ecosystem.

Current standards:

- XIP-000 - XIP Process
- XIP-001 - Manifest Standard (Draft)
- XIP-002 - Marketplace Standard (Draft)
- XIP-003 - Provenance Graph Standard (Draft)
- XIP-004 - Namespace Standard (Draft)
- XIP-005 - Software Package Standard (Draft)

XIP-001 is the shared envelope. XIP-002–005 profile or extend it: the contract
holds facts, manifests hold meaning, and dedicated contracts hold money and
names.
