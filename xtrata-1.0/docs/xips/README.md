# Xtrata Improvement Proposals (XIPs)

XIPs define standards, formats, conventions and interoperability rules for the Xtrata ecosystem.

Current reserved standards:

- XIP-000 - XIP Process
- XIP-001 - Manifest Standard
- XIP-002 - Marketplace Launch Standard (reserved)
- XIP-003 - Provenance Graph Standard (reserved)
- XIP-004 - Namespace Standard (reserved)
- XIP-005 - Software Package Standard (reserved)
