# XST token plan

This folder documents the proposed XST token and the single-inscription oracle viewer.

## Goals
- Emit XST starting when inscription ID 1000 is minted.
- Keep the token contract and the oracle inscription tightly linked.
- Provide a permanent, public viewer that shows live distribution and emission stats.

## Documents
- 01-product-brief.md - product intent and user impact.
- 02-contract-design.md - token contract design and read-only surface.
- 03-inscription-oracle.md - oracle inscription viewer design.
- 04-emissions-and-distribution.md - schedule, pools, and formulas.
- 05-integration-plan.md - implementation phases and tests.
